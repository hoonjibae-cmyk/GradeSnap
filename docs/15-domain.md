# 15. 도메인 연결 — `gradesnap.yussam.com`

**작성일**: 2026-08-08 · 등록기관: 가비아 · 호스팅: Vercel

앱 코드에 주소가 박힌 곳은 없습니다(확인함). **코드 수정도 재배포도 필요 없고**,
DNS 레코드 하나와 Vercel 설정 하나면 끝납니다.

---

## 15.1 순서

### 1) Vercel에 도메인 추가

```
Vercel → 프로젝트 → Settings → Domains → Add
gradesnap.yussam.com
```

추가하면 Vercel이 **넣어야 할 CNAME 값**을 화면에 띄웁니다. 보통
`cname.vercel-dns.com`이고, 계정에 따라 다른 값이 나올 수 있으니
**화면에 뜬 값을 그대로** 쓰십시오.

> 다른 Vercel 계정이 이미 이 도메인을 쓰고 있으면 TXT 레코드로 소유 확인을
> 요구합니다. 처음 붙이는 것이라면 안 나옵니다.

### 2) 가비아에 CNAME 하나

```
My가비아 → 서비스관리 → 도메인 → yussam.com → DNS 정보 → DNS 관리 → 레코드 수정
```

| 타입 | 호스트 | 값 | TTL |
|---|---|---|---|
| CNAME | `gradesnap` | `cname.vercel-dns.com.` | 3600 |

**두 가지를 조심하십시오.**

- **호스트는 `gradesnap`만** 적습니다. `gradesnap.yussam.com`을 적으면
  `gradesnap.yussam.com.yussam.com`이 됩니다.
- **값 끝에 점(`.`)** 을 붙입니다. 가비아는 점이 없으면 뒤에 도메인을 또 붙입니다.
  (입력창이 점을 거부하면 점 없이 넣고 저장 후 조회해서 확인하십시오.)

`yussam.com` 본 도메인과 기존 홈페이지에는 **아무 영향이 없습니다.**
서브도메인 한 줄만 추가하는 것입니다.

> ⚠️ **전제: `yussam.com`이 가비아 네임서버를 쓰고 있어야 합니다.**
> Cloudflare 같은 다른 DNS를 쓰고 있다면 가비아가 아니라 **거기서** 레코드를
> 넣어야 합니다. `whois`나 가비아 도메인 정보의 네임서버 항목으로 확인하십시오.

### 3) 확인

가비아 TTL 때문에 **5~30분** 걸립니다.

```
Vercel → Domains 에 "Valid Configuration" 이 뜨면 완료
→ 인증서(HTTPS)는 자동 발급, 몇 분 더
```

### 4) Supabase — 지금 해두면 나중에 안 물립니다

```
Supabase → Authentication → URL Configuration → Site URL
https://gradesnap.yussam.com
```

지금은 비밀번호 로그인만 써서 리디렉션이 없어 **당장은 안 해도 돕니다.**
다만 나중에 비밀번호 재설정 메일을 켜면 그 링크가 Site URL로 갑니다.
지금 바꿔두는 비용이 0입니다.

### 5) 옛 주소를 새 주소로 넘기기 — **DNS 확인 후에**

```
Vercel 환경 변수:  CANONICAL_HOST = gradesnap.yussam.com
```

넣으면 `*.vercel.app`으로 들어와도 새 주소로 넘어갑니다(308).

> 🔴 **3번이 끝나기 전에는 넣지 마십시오.** 아직 안 붙은 주소로 넘기면
> 앱이 통째로 사라집니다. 그래서 자동으로 켜지지 않게 환경 변수로 뒀습니다.

미리보기 배포와 POST 요청은 안 넘깁니다 — 미리보기가 쓸모없어지거나
채점 요청이 두 번 나가는 것을 막기 위해서입니다.

---

## 15.2 🔴 조교들에게 미리 알릴 것

**브라우저는 새 주소를 완전히 다른 사이트로 취급합니다.** 넘어가지 않는 것:

| 안 넘어감 | 다시 해야 할 일 |
|---|---|
| 로그인 세션 | 새 주소에서 **다시 로그인** |
| 홈 화면 아이콘 | 새 주소에서 **다시 홈 화면에 추가**, 옛 아이콘은 삭제 |
| 저장된 '반'·'철자 엄격' 설정 | 새 주소에서 **다시 지정** |

채점 결과·사진·직원 계정은 **전부 그대로**입니다 — 그건 브라우저가 아니라
Supabase에 있습니다. 다시 하는 것은 브라우저에 저장된 것뿐입니다.

바꾸는 날은 **수업이 없는 날**로 잡으십시오. 조교가 학생 줄 세워놓고
로그인을 다시 하게 되면 안 됩니다.

---

## 15.3 안 해도 되는 것

| | 왜 |
|---|---|
| 코드 수정 | 앱에 주소가 박힌 곳이 없습니다 (`grep`으로 확인) |
| 재배포 | 도메인은 배포와 무관합니다 |
| 환경 변수 변경 | Supabase URL·API 키 전부 그대로 |
| 인증서 발급·갱신 | Vercel이 자동으로 합니다 |
| 가비아 웹호스팅 신청 | **필요 없습니다.** DNS만 씁니다 |

---

## 15.4 안 되면 볼 곳

| 증상 | 원인 |
|---|---|
| Vercel이 계속 "Invalid Configuration" | 호스트에 `gradesnap.yussam.com`을 통째로 적었거나, 값 끝의 점을 빠뜨림 |
| 주소는 뜨는데 가비아 안내 페이지가 나옴 | 네임서버가 가비아가 아니거나, A 레코드가 남아 있음 |
| HTTPS 경고 | 인증서 발급 전. 10분쯤 기다린 뒤 Vercel Domains에서 재시도 |
| 새 주소에서 로그인이 안 됨 | Supabase가 아니라 브라우저 문제 — 시크릿 창으로 확인 |
