# 07. 개발 로드맵

## 개요

| 단계 | 기간(추정) | 범위 | 완료 조건 |
|---|---|---|---|
| **Phase 0** | 1–2주 | 인식률 실험 | 실측 데이터로 기술 선택 확정 |
| **Phase 1** | 5–7주 | A·B유형 MVP | 실제 수업에서 단어 시험 채점 |
| **Phase 2** | 3–4주 | C유형 + 운영 기능 | 문장 암기 시험 채점 |
| **Phase 3** | 4–6주 | D·E유형 | 혼합·서술형 보조 채점 |
| **Phase 4** | 이후 | 확장 | 리포트, 오답노트, 재시험지 생성 |

## Phase 0 — 타당성 검증 (가장 중요)

**코드를 쓰기 전에 반드시 해야 합니다.**

> ✅ **1차 샘플 5장 분석 완료** → [08. 샘플 분석](08-sample-analysis.md)
> 회전·휨·악필 편차·인쇄 첫 글자 등 기획 단계에서 안 보이던 문제들이 드러났고,
> 설계에 반영했습니다. 다만 5장으로는 인식률을 측정할 수 없어 아래는 그대로 유효합니다.

### 0.0 채점 표기 규칙 확인 ← **가장 먼저**
샘플에서 선생님마다 채점 표기가 달랐습니다. 동그라미가 정답 표시인지 오답 표시인지
선생님별로 확인해 문서화합니다.
**이걸 잘못 알면 벤치마크 결과 전체가 뒤집힙니다.**

### 0.1 샘플 수집
- **워드마스터 단어시험 답안지 30장 이상** (1순위 대상, 아래 0.6 참조)
- **채점하기 전 상태**로 촬영 (빨간펜이 답안을 덮으면 인식 방해)
- **책상에 평평하게 놓고** 촬영 (손에 들면 종이가 휨)
- 잘 쓴 것뿐 아니라 **악필(전체의 20% 이상), 지운 자국, 칸을 벗어난 것, 무응답** 포함
- 휴대폰 촬영본 (스캐너 아님 — 실제 사용 환경과 같아야 함)
- 정답표 및 선생님 채점 결과 (= 정답 라벨)

> 이 단계가 프로젝트에서 가장 자주 미뤄지고, 미루면 가장 크게 손해 보는 부분입니다.
> 다음 시험 때 답안지를 버리지 말고 모아두는 것부터 시작하십시오.

### 0.2 인식 벤치마크
동일한 crop 세트에 대해 후보 기술들을 나란히 측정합니다.

| 대상 | 비교 후보 | 우선순위 |
|---|---|---|
| **영어 손글씨 단어 (첫 글자 인쇄)** | VLM(prefix 제공) vs VLM(미제공) vs 상용 OCR | **1** |
| 한국어 손글씨 단어 | 상용 OCR(국내/해외) vs VLM(정답 후보 제공) vs VLM(미제공) | 2 |
| 영어 손글씨 문장 | VLM 단독 | 3 |

측정 항목: 정확도 / 판독불가율 / **오인식률(치명적)** / 응답시간 / 건당 비용

**필체 등급별로 나눠 집계합니다.** 전체 평균은 의미가 없습니다.
(양호 / 보통 / 악필 — 사람이 먼저 3등급으로 분류한 뒤 측정)

### 0.3 정합 실험
기준 마커를 인쇄해 다양한 각도·조명에서 촬영, homography 오차를 mm 단위로 측정.
**crop 위치 오차 2mm 이내**가 목표입니다.
샘플에서 확인된 두 조건을 반드시 포함합니다:
- **90도 회전 촬영** — 좌상단 비대칭 마커로 방향이 판별되는지
- **손에 들고 찍어 휜 상태** — 휨 감지가 작동하는지, 어느 정도 휨까지 허용 가능한지

### 0.4 관대함 테스트
일부러 틀리게 쓴 답안 20건을 만들어 AI가 정답으로 판정하는지 확인.
정답 후보를 알려주는 방식의 최대 리스크가 여기 있습니다.
철자 1글자 오류(`hesitage` vs `heritage` 같은 실제 오답 유형)를 반드시 포함합니다.

### 0.5 마킹 판독 실험 *(연기)*
`유/반` 선택형은 이번 샘플에 없었습니다. 해당 시험지가 확보되는 시점으로 미룹니다.

### 0.6 대상 시험지 확정
샘플 분석 결과 **워드마스터 단어시험 26~50번(한글 뜻 → 영단어)** 이
가장 자동채점하기 쉬운 문항군으로 판단됩니다.
영어 손글씨 + 정답 1개 + 첫 글자 인쇄 확정.
벤치마크 결과로 이 판단을 확인합니다.

### Phase 0 산출물
- 기술 선택 확정 문서 (어떤 인식기를 어디에 쓸지)
- 임계값 초기값 + 필체 등급별 예상 검수율
- **판단 기준**: 영단어 인식 정확도 95% 이상 & 오인식률 1% 미만 → Phase 1 착수
- **필요하면 이 시점에 중단하거나 방향을 바꿉니다.**

## Phase 1 — MVP (단어시험)

### 대상 (샘플 분석 후 수정됨)
```
1순위  워드마스터 단어시험 26~50번   한글 뜻 → 영단어 (첫 글자 인쇄)
2순위  워드마스터 단어시험 1~25번    영단어 → 한글 뜻
3순위  유&반의어 Test               선택형 + 뜻
4순위  본문 빈칸 Test
```

**한 시험지의 일부 문항군만 자동채점하고 나머지는 검수로 넘기는 것**이
처음부터 가능해야 합니다. "50문항 중 25문항이 자동으로 끝난다"만으로도
선생님 입장에서는 충분한 이득이며, 이것이 현실적인 도입 경로입니다.

### 범위
```
✅ 교사 로그인, 반·학생 관리
✅ 템플릿 편집기 (PDF 업로드, 영역 드래그, 격자 복제, prefix 지정)
✅ 정답표 입력 (인정 답안 다중)
✅ 인쇄용 PDF 생성 (비대칭 마커 + QR 삽입)
✅ 모바일 촬영·업로드 + 즉시 품질 검사 (회전·휨·흐림·마커)
✅ 전처리 → 회전 판별 → 정합 → crop
✅ DictGrader (prefix 처리 포함)
✅ 확신도 라우팅
✅ 검수 화면 (키보드 조작, 세로 모드, 전 문항 검수 모드)
✅ 결과: 점수 / 오답 번호 / PASS·FAIL / 재시험 명단
✅ 정확도 지표 대시보드 (필체 등급별 분리 집계)

⏸ MarkGrader — 선택형 시험지가 들어오는 시점으로 연기
```

### 범위 밖
```
❌ 문장·서술형 채점
❌ 학생·학부모 열람
❌ 재시험지 자동 생성
❌ 통계 분석
```

### 작업 순서
1. DB 스키마 + 인증 + 반/학생 관리 *(1주)*
2. **템플릿 편집기** *(1.5주)* — 가장 오래 걸리고 가장 중요합니다
   50문항 2단 격자를 몇 번의 클릭으로 만들 수 있어야 합니다
3. 인쇄용 PDF 생성 *(0.5주)*
4. 워커: 전처리·회전판별·정합·crop *(1주)*
5. DictGrader *(1주)*
6. 촬영·업로드 UI + 품질 검사 *(0.5주)*
7. 검수 화면 *(1주)*
8. 결과 화면 + 지표 *(0.5주)*

### 현장 투입
- 처음 2주는 **수기 채점과 병행**합니다. 자동 결과를 참고만 하고 신뢰하지 않습니다.
- 매주 무작위 20장 전수 대조 감사
- 오채점률 0.5% 미만이 2주 연속 유지되면 병행을 중단합니다

### 완료 조건
- 단어 시험 30장 채점이 수기 대비 **절반 이하 시간**
- 자동 확정 오채점률 **< 0.5%**
- 선생님이 다음 시험에도 **자발적으로 사용**

## Phase 2 — C유형 + 운영

```
✅ SentenceGrader (문장 영작, rubric 기반)
✅ rubric 설정 UI (오류 항목별 정답/오답/검수)
✅ 관대함 회귀 테스트 세트 + 자동 실행
✅ 템플릿 복제 (지난 회차 → 정답만 교체)
✅ 인정 답안 자동 학습 (교사가 정답 처리한 표현을 사전에 추가 제안)
✅ 학생별 누적 이력
✅ 오프라인 촬영 후 지연 업로드
```

인정 답안 자동 학습은 **체감 효과가 큽니다.** 쓰면 쓸수록 검수량이 줄어듭니다.

---

## Phase 3 — D·E유형

```
✅ 혼합형 템플릿 지원 (한 시험지에 여러 문항 유형)
✅ 키워드 기반 채점 (문법 용법 서술 등)
✅ RubricGrader (조건 체크리스트)
✅ 부분점수 처리
✅ 교사 최종 확정 워크플로우
```

D유형은 **템플릿 등록 편의성**이 성패를 가릅니다.
답안이 흩어진 시험지의 영역을 30개씩 찍어야 한다면 아무도 쓰지 않습니다.
문항 자동 감지(번호 패턴 인식) 보조 기능을 이 단계에서 검토합니다.

## Phase 4 — 확장

```
· 학생·학부모 결과 리포트
· 오답 노트 자동 생성
· 틀린 문항만 모은 재시험지 자동 생성   ← 현장 가치 매우 높음
· 반별·문항별 통계 (전체가 틀린 문항 = 다시 가르쳐야 할 부분)
· 다른 과목 확장
```

## 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| **한국어 손글씨 인식률이 기대 이하** | 치명적 | Phase 0에서 조기 확인. 낮으면 영단어 문항군만 자동화하고 한글 뜻은 검수 전제로 설계 |
| **악필 학생 비중이 예상보다 큼** | 높음 | 샘플 5장 중 1장이 판독 곤란. 전 문항 검수 모드로 대응. 필체 등급별 지표 분리 |
| **템플릿 등록이 번거로워 안 쓰임** | 치명적 | 격자 복제·템플릿 복제에 개발 시간 충분히 배정 |
| 정합 오차로 조용한 오채점 | 치명적 | 마커 필수화, 미검출 시 채점 중단 |
| 손에 들고 찍어 종이가 휨 | 중간 | 촬영 규칙 + 휨 감지 후 재촬영 요청. 곡면 보정은 구현하지 않음 |
| 90도 회전 촬영 | 중간 | 좌상단 비대칭 마커로 방향 판별 (EXIF 미신뢰) |
| AI 채점이 관대함 | 높음 | rubric 분리, 회귀 테스트 세트 상시 운영 |
| 촬영 품질 편차 | 중간 | 촬영 즉시 품질 검사 + 재촬영 요청 |
| 인쇄 배율 오류로 좌표 어긋남 | 중간 | QR에 version 포함, 인쇄 안내 명시 |
| AI API 비용 | 낮음 | 문항당 비용 실측 후 상한 설정. 마킹은 로컬 처리 |
| 개인정보 (실명·답안 이미지) | 중간 | RLS, 서명 URL, 보관 기간 정책 |

## 확정이 필요한 사항

기획 단계에서 아직 정해지지 않은 것들입니다.

1. **호스팅** — 학원 내부 서버 / 클라우드 / 관리형(Supabase+Vercel) 중 선택
2. **개발 인력** — 1인 개발인지, 외주인지에 따라 일정이 2배까지 달라집니다
3. **1차 대상 선생님** — 전체 도입이 아니라 **1~2명으로 시작**해야 합니다
4. **답안 이미지 보관 기간** — 학원 개인정보 처리방침과 정합 필요
5. **AI API 예산 상한** — Phase 0 실측 후 결정
