# 06. 시험지 양식 가이드

> 🛑 **이 문서는 보류되었습니다 (2026-08-07).**
>
> 기준 마커·QR·답안선 규격은 **템플릿 좌표로 crop하기 위한** 준비물이었습니다.
> [12. 페이지 단위 채점](12-page-level-grading.md)으로 전환하면서 정합이 없어져
> 인쇄물에 손댈 이유가 사라졌습니다. **선생님은 시험지를 지금 그대로 쓰면 됩니다.**
>
> 촬영 지침(평평하게, 정면, 채점 전)만 유효하며 §5에 있습니다.

> **전제: 문제와 레이아웃은 그대로 둡니다.**
> 아래는 "답안을 어디서 읽을지"를 시스템이 안정적으로 찾기 위한 최소 규격이며,
> 학생·학부모가 보기에 시험지가 달라졌다고 느끼지 않는 수준입니다.

## 1. 반드시 필요한 3가지

### ① 기준 마커 (fiducial marks)

페이지 **네 모서리에 마커 4개**를 넣습니다.
**좌상단 마커만 다른 모양(이중 사각형)** 으로 만들어 페이지 방향을 판별합니다.

```
◧                              ■     ← 좌상단만 이중 사각형
   ┌──────────────────────┐
   │                      │
   │      (기존 시험지)    │
   │                      │
   └──────────────────────┘
■                              ■
```

| 항목 | 규격 |
|---|---|
| 크기 | 5 × 5 mm (좌상단은 이중 사각형, 외곽 5mm) |
| 위치 | 각 모서리에서 안쪽으로 10mm |
| 색 | 순수 검정 (K100) |
| 주변 여백 | 마커 둘레 3mm는 완전한 백지 |

**왜 필요한가**: 휴대폰으로 찍으면 시험지가 기울고 원근이 생깁니다.
마커 4점을 알면 촬영 이미지를 템플릿 좌표계로 정확히 되돌릴 수 있습니다.
마커가 없으면 crop이 몇 mm씩 어긋나고, **그 결과는 "조용히 틀린 채점"** 입니다.

**왜 좌상단만 다른가**: [샘플 분석](08-sample-analysis.md) 결과 실제 촬영본
**5장 전부가 90도 회전**되어 있었습니다. 세로 시험지를 가로로 들고 찍기 때문입니다.
네 마커가 모두 같은 모양이면 0°/90°/180°/270°를 구분할 수 없습니다.
EXIF 방향 정보는 신뢰할 수 없으므로 마커 자체가 방향을 알려줘야 합니다.

4개 중 3개만 검출돼도 처리 가능하지만(좌상단 포함 필수),
2개 이하면 채점을 중단하고 재촬영을 요청합니다.

또한 배경에 다른 종이가 깔려 있어 **문서 외곽선 검출은 신뢰할 수 없습니다**
(샘플 5장 중 4장에서 확인). 정합은 **오직 마커 4점에만** 의존합니다.

### ② QR 코드

**우측 상단**에 배치합니다.

| 항목 | 규격 |
|---|---|
| 크기 | 12 × 12 mm |
| 내용 | `GS:<template_code>:<page_no>:<version>` |
| 예시 | `GS:MG-H1-U1-SYNANT-01:1:3` |
| 오류 정정 레벨 | M 이상 |

**version이 중요합니다.** 좌표를 수정한 뒤 예전에 인쇄해둔 시험지가 섞여 들어오면
crop이 전부 어긋납니다. version이 다르면 시스템이 그 버전의 좌표를 사용하거나,
없으면 경고합니다.

다중 페이지 시험지는 **모든 페이지에 QR**을 넣습니다. 페이지 순서가 섞여도 됩니다.

### ③ 학생 식별

세 가지 중 하나를 선택합니다. **①을 권장합니다.**

| 방식 | 설명 | 정확도 | 비고 |
|---|---|---|---|
| **① 촬영 시 학생 선택** | 반 명단에서 탭 | 100% | 권장. 추가 인쇄 요소 없음 |
| ② 학번 4자리 마킹 | 숫자 칸 4개를 채움 | 높음 | 시험지 상단에 칸 추가 필요 |
| ③ 이름 OCR + 확인 | 이름란을 읽고 후보 제시 | 보통 | 동명이인 문제 |

실무적으로는 **①과 ③의 조합**이 가장 빠릅니다.
이름란 crop을 보여주면서 명단에서 자동 추천하고, 선생님이 탭 한 번으로 확정합니다.

## 2. 답안 영역 규격

### 손글씨 작성선

| 항목 | 규격 | 이유 |
|---|---|---|
| 높이 | **최소 9mm** (권장 11mm) | 한글 손글씨가 칸을 넘지 않을 최소 높이 |
| 밑줄 굵기 | 0.4pt | 굵으면 글씨와 붙어 인식 방해 |
| 밑줄 색 | **연회색 (K30)** | 검정 실선은 제거가 어려움. 회색은 깔끔히 분리됨 |
| 좌우 여백 | 좌 2mm, 우 2mm | |
| 위아래 여백 | 3mm 이상 | 윗줄 글씨가 아랫줄 답안 영역을 침범하지 않게 |

> 밑줄을 **점선 또는 연회색**으로 바꾸는 것만으로 인식률이 눈에 띄게 올라갑니다.
> 시각적으로는 거의 차이가 없습니다.

### 선택형 (`유 / 반` 등)

```
권장:   ( 유 )    ( 반 )        ← 각 선택지를 괄호/원으로 감싸고 간격 확보
비권장:  유 / 반                 ← 붙어 있어 동그라미가 양쪽을 침범
```

| 항목 | 규격 |
|---|---|
| 선택지 간 간격 | 최소 6mm |
| 선택지 영역 크기 | 6 × 6 mm 이상 |
| 학생 지시 | "선택지에 **동그라미**를 치세요" (체크·빗금 혼용 시 판독 어려움) |

### 빈칸형 (본문 중간 빈칸)

| 항목 | 규격 |
|---|---|
| 빈칸 길이 | 정답 단어 길이 × 1.5 이상, 최소 15mm |
| 빈칸 높이 | 9mm 이상 |
| 빈칸 간 간격 | 최소 5mm |
| 행간 | 기존보다 1.2배 |

### 서술형 답안란

| 항목 | 규격 |
|---|---|
| 형태 | 여러 줄이면 줄마다 밑줄, 단일 답이면 박스 |
| 줄 높이 | 11mm 이상 |
| 본문과의 거리 | 3mm 이상 |

## 3. 인쇄·촬영 규칙

### 인쇄
- **배율 100% 고정.** "용지에 맞춤" 옵션을 끄십시오. 축소 인쇄되면 좌표가 어긋납니다.
- A4 흰 용지. 재생지·색지는 대비가 떨어집니다.
- 양면 인쇄 시 뒷면 비침 주의 (80g/㎡ 이상 권장)
- 스테이플러는 **좌상단**에만. 답안 영역·마커를 가리면 안 됩니다.

### 촬영

> 실제 샘플 5장 중 **잘 찍힌 것은 1장뿐**이었습니다. 촬영 규칙은 정확도에
> 인식 기술 선택만큼이나 큰 영향을 줍니다. 아래 3가지는 반드시 지켜야 합니다.

**① 책상에 평평하게 놓고 찍는다 — 손에 들고 찍지 않는다**
손으로 잡으면 종이가 곡면으로 휘고, 평면 보정으로는 되돌릴 수 없습니다.
가운데 부분의 좌표가 수 mm씩 밀려 crop이 어긋납니다.

**② 채점하기 전에 찍는다**
빨간펜 채점 표시가 학생 답안 위에 겹치면 인식이 방해받습니다.
촬영 → 자동채점 → 검수 순서이므로 원래 채점 표시가 있을 이유가 없습니다.

**③ 회전은 신경 쓰지 않아도 된다**
가로로 들고 찍어도 됩니다. 마커로 방향을 자동 판별합니다.

그 외:
- 시험지 전체가 프레임에 들어오게 (마커 4개 포함)
- 그림자 주의 — 형광등 아래 정면 촬영, 몸으로 그늘 만들지 않기
- 접힌 자국이 답안 위를 지나가지 않게
- 기울기 15도 이내
- 가능하면 배경을 비우기 (다른 시험지 위에 겹쳐 놓지 않기 — 필수는 아님)

앱이 촬영 즉시 품질을 검사해 **문제가 있으면 그 자리에서 재촬영을 요청**합니다.
검사 항목: 마커 검출 수 / 흐림 / 기울기 / **휨**(마커 4점 사각형의 대각선 비율 이상).
나중에 발견하면 학생이 이미 집에 간 뒤입니다.

## 4. 유형별 수정 체크리스트

### A유형 (유&반의어) — 수정 최소
- [ ] 기준 마커 4개
- [ ] 우상단 QR
- [ ] `유`/`반` 사이 간격 6mm 확보, 각각 괄호로 감싸기
- [ ] `뜻:` 작성선 높이 9mm, 연회색으로 변경
- [ ] 이름란 폭 확보

### B유형 (본문 빈칸)
- [ ] 기준 마커 4개 + QR
- [ ] 빈칸 높이 9mm 이상으로 확대
- [ ] 행간 1.2배
- [ ] 문항 번호를 왼쪽 고정 열에 정렬

### C유형 (문장 영작)
- [ ] 기준 마커 4개 + QR
- [ ] `→` 뒤 작성 공간 폭 전체, 높이 11mm 확보
- [ ] 2줄 이상 필요한 문장은 2줄 제공

### D유형 (본문분석 혼합) — 수정 폭 가장 큼
- [ ] 기준 마커 4개 + QR
- [ ] **답안마다 번호 부여** — `① (at / in)`, `② *to부정사의 용법:`
- [ ] 선택형 위치 고정, 본문과 3mm 이상 분리
- [ ] 서술형 답안선을 한 줄 형식으로 통일
- [ ] 본문 위 여백에 답을 쓰게 하는 형태는 지양

### E유형 (고난도 서술형)
- [ ] 기준 마커 4개 + QR
- [ ] 서술형 2 (단어 빈칸) — A~D 빈칸을 같은 크기·간격으로 정렬
- [ ] 서술형 1·3 — 답안 박스 명확히 구획

## 5. 템플릿 등록 절차 (선생님용)

```
1. 평소처럼 한글/워드로 시험지를 만든다
2. PDF로 저장
3. GradeSnap에 업로드
4. 화면에서 답안 영역을 드래그해 지정
   · 규칙적으로 반복되는 문항은 1개만 지정 후 "격자 복제"
5. 정답 입력 (인정 답안 여러 개 가능)
6. PASS 기준 설정
7. 저장 → 마커·QR이 삽입된 인쇄용 PDF 다운로드
8. 이 PDF로 인쇄한다   ← 원본 PDF가 아니라 이것으로!
```

지난 회차 템플릿을 **복제해 정답만 교체**하면 2회차부터는 1~2분이면 끝납니다.
