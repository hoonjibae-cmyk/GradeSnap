# 구글 폴더에서 정답지 가져오기 — 붙이는 법

선생님들은 이미 매번 정답지를 구글 폴더에 올립니다. 조교가 그걸 다시 종이로
뽑아 사진 찍는 것은 **같은 일을 두 번 하는 것**입니다. 그래서 프로그램이 그
폴더를 직접 봅니다.

설계 근거는 [docs/13 §13.45](13-phase1-plan.md)에 있습니다. **여기는 손으로 할
일만** 적습니다. 한 번만 하면 되고, 15분쯤 걸립니다.

---

## 먼저 알아 둘 것

- **아무것도 안 해도 프로그램은 그대로 돕니다.** 아래를 안 하면 「구글 폴더에서
  가져오기」 칸이 화면에 아예 안 뜨고, 정답지를 사진으로 올리는 길만 남습니다.
- **읽기만 합니다.** 프로그램은 선생님들의 폴더에 쓸 수도 지울 수도 없습니다.
  권한을 `drive.readonly` 하나로 묶어 뒀습니다.
- **선생님들이 하던 일은 안 바뀝니다.** 지금처럼 올리시면 됩니다.

---

## 1. 구글에 프로그램용 계정 만들기 (무료)

사람 계정이 아니라 **프로그램이 쓰는 계정**입니다. 구글에서는 이걸 '서비스
계정'이라고 부릅니다.

1. <https://console.cloud.google.com> 에 학원 구글 계정으로 들어갑니다.
2. 위쪽에서 **프로젝트 만들기** — 이름은 `GradeSnap` 아무거나 됩니다.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API`를 찾아
   **사용** 을 누릅니다. **이걸 빼먹으면 나중에 403이 납니다.**
4. 왼쪽 메뉴 **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기**
   - 이름: `gradesnap-drive`
   - 역할은 **안 줘도 됩니다.** 폴더 권한은 3번에서 따로 줍니다.
5. 만들어진 계정을 눌러 **키 → 키 추가 → 새 키 만들기 → JSON**.
   파일이 하나 내려옵니다. **이 파일이 열쇠입니다 — 아무에게도 보내지
   마십시오.** 카카오톡·메일로 옮기지 말고, 아래 3번에서 값을 붙여 넣은 뒤
   컴퓨터에서 지우십시오.

내려받은 JSON 안에서 두 값을 씁니다.

```json
{
  "client_email": "gradesnap-drive@....iam.gserviceaccount.com",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMII...\n-----END PRIVATE KEY-----\n"
}
```

## 2. 정답지 폴더를 그 계정에 공유하기

구글 드라이브에서 **정답지 상위 폴더**(선생님별 폴더들이 들어 있는 그 폴더)를
엽니다.

1. 폴더 우클릭 → **공유**
2. 위 `client_email` 주소를 붙여 넣습니다.
3. 권한은 **뷰어**. 🔴 편집자로 주지 마십시오 — 프로그램이 정답지를 지울 수
   있게 됩니다.
4. **보내기**.

하위 폴더는 따로 공유 안 해도 됩니다. 상위 폴더 권한이 그대로 내려갑니다.

## 3. Vercel에 값 넣기

Vercel 프로젝트 → **Settings → Environment Variables**. 세 개를 넣습니다.

| 이름 | 값 | 노출 |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | JSON의 `client_email` | 서버 전용 |
| `GOOGLE_SERVICE_ACCOUNT_KEY` | JSON의 `private_key` **통째로** | 🔴 **서버 전용. 개인 열쇠입니다** |
| `DRIVE_FOLDER_ID` | 폴더 주소의 `/folders/` 뒤 문자열 | 서버 전용 |

```
https://drive.google.com/drive/folders/1L6j425t9iL7V4caJEi9_zNHPNI9-CJ-G?usp=sharing
                                       └──────────── DRIVE_FOLDER_ID ────────────┘
```

`private_key`는 줄바꿈이 `\n`으로 적혀 있습니다. **그대로 붙여 넣으십시오** —
프로그램이 되돌려 씁니다.

🔴 **이름 앞에 `NEXT_PUBLIC_`을 붙이지 마십시오.** 붙이면 열쇠가 브라우저로
나가고, 그 폴더를 아무나 읽게 됩니다.

넣은 뒤 **재배포**해야 적용됩니다.

## 4. 확인

`/keys` 화면(위 메뉴의 「정답지」)을 엽니다.

| 보이는 것 | 뜻 |
|---|---|
| 「구글 폴더에서 가져오기」와 파일 목록 | 됐습니다 |
| 아무것도 안 보임 | 환경 변수 셋 중 하나가 비었거나, 재배포를 안 했습니다 |
| 「읽을 권한이 없습니다 (403)」 | 2번 공유를 안 했거나, 1-3번(Drive API 사용)을 빼먹었습니다 |
| 「열쇠를 읽을 수 없습니다」 | `private_key`가 잘렸습니다. `-----BEGIN PRIVATE KEY-----`부터 끝까지 다시 붙여 넣으십시오 |
| 목록은 뜨는데 파일이 0개 | 파일 이름에 **「답지」**가 없습니다 (아래 참고) |

## 어느 파일을 정답지로 보는가

**파일 이름에 「답지」가 들어 있는 것**만 가져옵니다. 그것뿐입니다.

선생님마다 이름 짓는 방식이 전혀 다르기 때문입니다 — 날짜 적는 법도, 구분
기호도, 순서도 제각각입니다. 실제로 올라와 있는 것들입니다.

```
08040805워드마스터unit33-34 단어 답지.pdf
0827_M9(A,B)_Day1-3_재시_답지.pdf
0831,0901,0903,0904_5과 본문암기 Test (1차)_답지.pdf
8월27일(28일) 목(금)_미사고2_교과서 3과 어휘 test 답지_커트 -10(오답필수)_김은진T.pdf
```

공통된 것은 「답지」 두 글자뿐이고, 규칙을 더 얹으면 **어느 선생님의 파일이
통째로 안 보이게 됩니다.** 시험지 파일(`…시험지.pdf`)에는 「답지」가 안
들어가서 저절로 걸러집니다.

선생님들께 부탁드릴 것이 있다면 하나뿐입니다 — **정답지 파일 이름에 「답지」를
넣어 주십시오.** 지금도 대부분 그렇게 하고 계십니다.

## PDF만 읽습니다

한글(.hwp)·워드 파일은 글자를 못 꺼냅니다. 목록에는 뜨지만 「PDF가 아님」으로
표시되고 「읽기」가 눌리지 않습니다.

**스캔본 PDF도 못 읽습니다.** 종이를 복사기로 밀어 넣어 만든 PDF는 속이 사진
한 장이라 꺼낼 글자가 없습니다. 그때는 화면이 그렇게 말해 주고, **사진으로
올리면 됩니다.**

## 값

파일 목록을 읽는 것은 **돈이 안 나갑니다.** PDF에서 글자를 꺼내는 것도
공짜입니다 — 읽는 게 아니라 들어 있는 값을 꺼내는 것입니다.

돈이 나가는 것은 **꺼낸 글자를 문항으로 가르는 한 번**뿐입니다. 시험 하나에
한 번이고, 사진을 보내는 것보다 훨씬 쌉니다.

## 🔴 「읽기」는 저장이 아닙니다

가져온 결과는 화면의 표에 채워질 뿐입니다. **사람이 보고 「등록」을 눌러야**
저장됩니다.

자동으로 집어넣지 않는 이유는 하나입니다 — **정답지가 틀리면 그 시험을 본 반
전체가 같은 오류로 채점됩니다.** 그 실수를 잡을 수 있는 곳이 여기뿐입니다.
