# 구글 폴더에서 정답지 가져오기 — 붙이는 법

선생님들은 이미 매번 정답지를 구글 폴더에 올립니다. 조교가 그걸 다시 종이로
뽑아 사진 찍는 것은 **같은 일을 두 번 하는 것**입니다. 그래서 프로그램이 그
폴더를 직접 봅니다.

설계 근거는 [docs/13 §13.45](13-phase1-plan.md)에 있습니다. **여기는 손으로 할
일만** 적습니다. 한 번만 하면 되고, 15분쯤 걸립니다.

---

## 먼저 알아 둘 것

- **아무것도 안 해도 프로그램은 그대로 돕니다.** 아래를 안 하면 「구글 폴더에서
  가져오기」 칸이 화면에 아예 안 뜨고, 정답지를 사진으로 올리는 길만 남습니다.
- **읽기만 합니다.** 프로그램은 선생님들의 폴더에 쓸 수도 지울 수도 없습니다.
  권한을 `drive.readonly` 하나로 묶어 뒀습니다.
- **선생님들이 하던 일은 안 바뀝니다.** 지금처럼 올리시면 됩니다.

---

## 준비물

- **정답지 폴더를 공유할 수 있는 구글 계정** (그 폴더의 소유자이거나 관리 권한이 있어야 합니다)
- **Vercel 접근 권한** (환경 변수를 넣을 수 있어야 합니다)

둘 다 원장님 계정이면 혼자 끝납니다. 30분 잡으면 넉넉합니다.

---

## 1단계 · 구글 클라우드에 프로젝트 만들기

1. <https://console.cloud.google.com> 에 **학원 구글 계정으로** 들어갑니다.
   처음이면 약관 동의 화면이 한 번 나옵니다.
2. 화면 **맨 위 왼쪽**, 구글 클라우드 로고 옆의 **프로젝트 선택기**를 누릅니다.
   (아직 없으면 `프로젝트 선택`이라고 쓰여 있습니다)
3. 뜬 창에서 오른쪽 위 **새 프로젝트**.
4. 이름에 `GradeSnap` — 위치는 그대로 두고 **만들기**.
5. 만들어지면 다시 **프로젝트 선택기를 눌러 `GradeSnap`을 고릅니다.**

🔴 **5번을 꼭 확인하십시오.** 프로젝트를 만들어 놓고 선택을 안 하면, 다음
단계들이 **엉뚱한 프로젝트에** 만들어집니다. 화면 맨 위에 `GradeSnap`이
쓰여 있어야 합니다.

## 2단계 · Drive API 켜기

프로그램이 드라이브를 읽으려면 이 스위치가 켜져 있어야 합니다.
**여기를 빼먹는 것이 제일 흔한 사고**이고, 증상은 나중에 403 오류입니다.

1. 왼쪽 위 **☰ (햄버거 메뉴)** → **API 및 서비스** → **라이브러리**
2. 검색창에 `Google Drive API` 를 칩니다.
3. 나온 결과를 누르고 → 파란 **사용**(Enable) 버튼.
4. 버튼이 **관리**로 바뀌면 켜진 것입니다.

## 3단계 · 서비스 계정 만들기

사람 계정이 아니라 **프로그램이 쓰는 계정**입니다.

1. ☰ → **IAM 및 관리자** → **서비스 계정**
2. 위쪽 **+ 서비스 계정 만들기**
3. **서비스 계정 이름**: `gradesnap-drive`
   (아래 계정 ID는 자동으로 채워집니다. 그대로 둡니다) → **만들고 계속하기**
4. 다음 화면 **"이 서비스 계정에 프로젝트에 대한 액세스 권한 부여"** —
   **아무것도 고르지 말고 계속** 을 누릅니다.
   🔴 여기서 역할을 주면 안 됩니다. 폴더 권한은 5단계에서 따로 줍니다.
5. 마지막 화면도 비운 채 **완료**.
6. 목록에 줄이 하나 생깁니다. 거기 적힌 **이메일 주소를 복사해 메모장에
   붙여 두십시오.** 이렇게 생겼습니다:

```
gradesnap-drive@gradesnap-471203.iam.gserviceaccount.com
```

이 주소를 **5단계와 6단계에서 씁니다.**

## 4단계 · 열쇠 파일 내려받기

1. 방금 만든 서비스 계정 **이름을 클릭**해 들어갑니다.
2. 위쪽 탭에서 **키**(Keys)
3. **키 추가** → **새 키 만들기** → **JSON** 선택 → **만들기**
4. `.json` 파일이 자동으로 내려옵니다.

🔴 **이 파일이 비밀번호입니다.** 카카오톡·메일로 옮기지 마십시오. 6단계에서
값을 붙여 넣고 나면 **파일을 지우고 휴지통까지 비우십시오.**

> **키 만들기가 막혀 있다면** — 학원 구글 계정이 조직으로 묶여 있으면 조직
> 정책이 서비스 계정 키 생성을 금지하는 경우가 있습니다. "조직 정책에 의해
> 사용 중지됨" 같은 문구가 뜨면 거기서 멈추고 알려 주십시오. 다른 방법이
> 있습니다.

## 5단계 · 정답지 폴더 공유하기

1. <https://drive.google.com> 에서 **정답지 상위 폴더**를 찾습니다.
   (선생님별 폴더들이 들어 있는 그 폴더입니다)
2. 폴더에 **마우스 오른쪽 클릭** → **공유** → **공유**
3. 사람 추가 칸에 **3단계에서 복사해 둔 이메일 주소**를 붙여 넣습니다.
4. 오른쪽 권한을 **뷰어**로 둡니다.
   🔴 **편집자로 주지 마십시오.** 프로그램이 정답지를 지울 수 있게 됩니다.
5. **보내기** (또는 **공유**).

알림 메일 체크는 꺼도 됩니다 — 서비스 계정은 메일을 못 받습니다.

하위 폴더는 따로 안 해도 됩니다. 상위 폴더 권한이 그대로 내려갑니다.

## 6단계 · Vercel에 값 세 개 넣기

4단계에서 받은 JSON 파일을 **메모장으로** 엽니다. 이렇게 생겼습니다:

```json
{
  "type": "service_account",
  "project_id": "gradesnap-471203",
  "private_key_id": "a1b2c3...",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQIBAD...\n-----END PRIVATE KEY-----\n",
  "client_email": "gradesnap-drive@gradesnap-471203.iam.gserviceaccount.com",
  ...
}
```

<https://vercel.com> → **GradeSnap 프로젝트** → **Settings** → **Environment
Variables**. 아래 세 개를 하나씩 **Add** 합니다.

| Key (이름) | Value (값) |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | JSON의 `client_email` 값 |
| `GOOGLE_SERVICE_ACCOUNT_KEY` | JSON의 `private_key` 값 **통째로** |
| `DRIVE_FOLDER_ID` | 폴더 주소의 `/folders/` 뒤 문자열 |

각각 **Production · Preview · Development 를 모두 체크**한 뒤 Save 합니다.

`DRIVE_FOLDER_ID`는 폴더 주소에서 가져옵니다:

```
https://drive.google.com/drive/folders/1L6j425t9iL7V4caJEi9_zNHPNI9-CJ-G?usp=sharing
                                       └──────────── 이 부분만 ────────────┘
```

`private_key`는 **`-----BEGIN PRIVATE KEY-----` 부터 `-----END PRIVATE KEY-----`
까지 전부**입니다. 중간의 `\n`은 **그대로 두십시오** — 프로그램이 되돌려
씁니다. 감싼 따옴표가 같이 붙어도 프로그램이 떼어 냅니다.

🔴 **이름 앞에 `NEXT_PUBLIC_`을 붙이지 마십시오.** 붙이면 열쇠가 브라우저로
나가고, 그 폴더를 아무나 읽게 됩니다.

## 7단계 · 재배포

환경 변수는 **넣기만 해서는 적용이 안 됩니다.**

Vercel → **Deployments** 탭 → 맨 위 배포 오른쪽 **⋯** → **Redeploy** →
**Redeploy** 확인. 1~2분 걸립니다.

## 9단계 · 뒷정리

4단계에서 내려받은 **JSON 파일을 지우고 휴지통을 비웁니다.** 값은 이미
Vercel에 들어갔으니 파일은 더 쓸 데가 없고, 남아 있으면 그 자체가 위험입니다.

## 어느 파일을 정답지로 보는가

**파일 이름에 「답지」가 들어 있는 것**만 가져옵니다. 그것뿐입니다.

선생님마다 이름 짓는 방식이 전혀 다르기 때문입니다 — 날짜 적는 법도, 구분
기호도, 순서도 제각각입니다. 실제로 올라와 있는 것들입니다.

```
08040805워드마스터unit33-34 단어 답지.pdf
0827_M9(A,B)_Day1-3_재시_답지.pdf
0831,0901,0903,0904_5과 본문암기 Test (1차)_답지.pdf
8월27일(28일) 목(금)_미사고2_교과서 3과 어휘 test 답지_커트 -10(오답필수)_김은진T.pdf
```

공통된 것은 「답지」 두 글자뿐이고, 규칙을 더 얹으면 **어느 선생님의 파일이
통째로 안 보이게 됩니다.** 시험지 파일(`…시험지.pdf`)에는 「답지」가 안
들어가서 저절로 걸러집니다.

선생님들께 부탁드릴 것이 있다면 하나뿐입니다 — **정답지 파일 이름에 「답지」를
넣어 주십시오.** 지금도 대부분 그렇게 하고 계십니다.

## PDF만 읽습니다

한글(.hwp)·워드 파일은 글자를 못 꺼냅니다. 목록에는 뜨지만 「PDF가 아님」으로
표시되고 「읽기」가 눌리지 않습니다.

**스캔본 PDF도 못 읽습니다.** 종이를 복사기로 밀어 넣어 만든 PDF는 속이 사진
한 장이라 꺼낼 글자가 없습니다. 그때는 화면이 그렇게 말해 주고, **사진으로
올리면 됩니다.**

## 값

파일 목록을 읽는 것은 **돈이 안 나갑니다.** PDF에서 글자를 꺼내는 것도
공짜입니다 — 읽는 게 아니라 들어 있는 값을 꺼내는 것입니다.

돈이 나가는 것은 **꺼낸 글자를 문항으로 가르는 한 번**뿐입니다. 시험 하나에
한 번이고, 사진을 보내는 것보다 훨씬 쌉니다.

## 🔴 「읽기」는 저장이 아닙니다

가져온 결과는 화면의 표에 채워질 뿐입니다. **사람이 보고 「등록」을 눌러야**
저장됩니다.

자동으로 집어넣지 않는 이유는 하나입니다 — **정답지가 틀리면 그 시험을 본 반
전체가 같은 오류로 채점됩니다.** 그 실수를 잡을 수 있는 곳이 여기뿐입니다.
