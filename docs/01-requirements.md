# 01. 제품 요구사항

## 1. 배경

영어 학원에서 단어 시험·본문 빈칸·문장 암기·서술형 시험을 매일 다량으로 실시합니다.
채점은 전부 수기로 이루어지며, 선생님 1인 기준 하루 수십~수백 장을 채점합니다.
채점 자체보다도 **오답 정리, 재시험 대상 추출, 학생별 누적 관리**에 시간이 더 듭니다.

기존 자동채점 솔루션은 대부분 OMR 전용 답안지를 요구합니다.
그러나 이 학원의 시험지는 선생님마다 양식이 다르고, 본문·빈칸·서술형이 섞여 있어
OMR 답안지로 전환하면 시험 자체의 성격이 바뀝니다.

**따라서 GradeSnap의 전제는 "양식을 바꾸지 않는다"입니다.**

## 2. 사용자

| 역할 | 하는 일 |
|---|---|
| **선생님(교사)** | 시험지 템플릿 등록, 정답표 입력, 답안지 촬영·업로드, 검수, 결과 확인 |
| **관리자(원장)** | 반·학생 관리, 교사 계정 관리, 전체 통계 확인 |
| **학생/학부모** *(2차)* | 결과 리포트, 오답 노트 열람 |

MVP 단계에서는 **선생님만** 시스템을 사용합니다. 학생은 기존과 똑같이 종이에 시험을 봅니다.

## 3. 핵심 사용 시나리오

### S1. 시험지 등록 (시험 전, 1회)
1. 선생님이 시험지 PDF를 업로드한다.
2. 화면에 PDF가 렌더링되고, 선생님은 마우스로 각 문항의 **답안 영역을 드래그**해 지정한다.
3. 각 영역에 문항 번호·유형(선택형/단답/문장형)·배점을 지정한다.
4. 정답표를 입력한다. 단답형은 **인정 답안을 여러 개** 등록할 수 있다.
   (예: `respond` → 응답하다 / 대답하다 / 반응하다)
5. PASS 기준을 설정한다. (예: 20문항 중 3개까지 PASS)
6. 저장하면 시스템이 **QR코드와 기준 마커가 삽입된 인쇄용 PDF**를 생성한다.

> 이 화면이 GradeSnap의 심장입니다. 여기가 쓰기 불편하면 시스템 전체가 안 쓰입니다.
> 문항이 규칙적으로 반복되는 시험지(유&반의어 Test 등)는 **1행을 지정한 뒤 "20개로 복제"**
> 같은 격자 자동 생성 기능이 반드시 필요합니다.

### S2. 채점 (시험 후, 매회)
1. 시험지를 인쇄해 평소대로 시험을 본다.
2. 선생님이 답안지를 휴대폰으로 연속 촬영한다. (한 장씩, 혹은 여러 장 일괄)
3. 업로드하면 시스템이 QR로 시험지를 식별하고, 학생을 식별한다.
   - 학생 식별: ① 촬영 전 반 선택 후 학생 지정 ② 학번 4자리 마킹 ③ 이름 OCR + 확인
4. 자동채점이 돌아간다. (수 초 ~ 수십 초)
5. **확신도가 낮은 문항만** 검수 화면에 뜬다. 선생님은 잘라낸 답안 이미지를 보며
   맞음/틀림을 키보드로 빠르게 확정한다.
6. 확정하면 점수·오답 번호·PASS/FAIL이 저장된다.

### S3. 결과 활용
- 반별 성적표, 학생별 누적 점수
- **재시험 대상 자동 추출** (PASS 기준 미달자)
- 오답 문항 통계 (반 전체가 틀린 문항 = 다시 가르쳐야 할 부분)
- *(2차)* 틀린 문항만 모은 재시험지 자동 생성

## 4. 기능 요구사항

### FR-1 템플릿
- FR-1.1 PDF/이미지 업로드, 다중 페이지 지원
- FR-1.2 답안 영역 시각적 지정 (드래그), 격자 복제, 좌표 미세 조정
- FR-1.3 문항 유형: 선택형(마킹), 단답형(손글씨 단어), 문장형(손글씨 문장), 체크형
- FR-1.4 한 문항에 여러 답안 영역 허용 (본문 빈칸형 — 1문항에 빈칸 5개)
- FR-1.5 정답표 입력: 정답, 인정 변형 답안, 채점 규칙(대소문자·철자오류·구두점 허용 여부)
- FR-1.6 PASS 기준: `틀린 개수 ≤ N` 또는 `점수 ≥ N%`
- FR-1.7 QR + 기준 마커가 삽입된 인쇄용 PDF 출력
- FR-1.8 템플릿 복제 (지난 회차 템플릿을 복사해 정답만 교체)

### FR-2 촬영·업로드
- FR-2.1 모바일 웹에서 카메라 촬영 (앱 설치 불필요)
- FR-2.2 다중 파일 일괄 업로드
- FR-2.3 촬영 즉시 품질 검사 — 흐림·잘림·기준 마커 미검출 시 **그 자리에서 재촬영 요청**
- FR-2.4 오프라인 촬영 후 나중에 업로드 (네트워크 불안정 대비)

### FR-3 채점
- FR-3.1 원근 보정, 회전 보정, 그림자·조명 보정
- FR-3.2 QR 기반 시험지 자동 식별 (실패 시 수동 선택)
- FR-3.3 기준 마커 기반 정합 → 템플릿 좌표계로 정규화
- FR-3.4 유형별 채점 (→ [05. 채점 엔진](05-grading-engine.md))
- FR-3.5 문항별 확신도 산출 및 임계값 기반 검수 라우팅
- FR-3.6 임계값은 선생님이 조정 가능 (엄격 ↔ 빠름)

### FR-4 검수
- FR-4.1 잘라낸 답안 이미지 + 인식 결과 + 정답 + AI 판단 근거를 한 화면에
- FR-4.2 키보드 단축키로 연속 처리 (O / X / 부분점수 / 다음)
- FR-4.3 교사 판정은 항상 AI 판정을 덮어씀, 변경 이력 기록
- FR-4.4 원본 전체 이미지 확대 보기 (잘린 부분이 애매할 때)

### FR-5 결과
- FR-5.1 학생별 점수·오답 번호·PASS 여부
- FR-5.2 반별 결과 목록, 재시험 명단 추출
- FR-5.3 학생별 누적 이력
- FR-5.4 문항별 정답률 통계

### FR-6 관리
- FR-6.1 학원 / 교사 / 반 / 학생 관리
- FR-6.2 교사는 본인 반 데이터만, 원장은 전체 열람

## 5. 비기능 요구사항

| 항목 | 목표 |
|---|---|
| 채점 지연 | 1장당 15초 이내 (업로드 완료 → 결과) |
| 처리 규모 | 하루 300장 / 피크 시 동시 30장 |
| **자동 확정 항목 오채점률** | **0.5% 미만** (가장 중요한 지표) |
| 검수 필요 비율 | 초기 30% 이하 → 안정화 후 10% 이하 |
| 가용성 | 학원 운영 시간(14:00–23:00) 기준 안정 동작 |
| 보안 | 학생 실명·답안 이미지 포함 → 접근 통제, 보관 기간 정책 필수 |

## 6. 범위 밖 (명시적 제외)

- 학생이 태블릿·PC로 시험 보는 온라인 응시 (종이 시험 유지가 전제)
- 시험지 저작·편집 기능 (선생님은 계속 한글/워드로 만든다)
- 영어 외 과목 (구조상 확장 가능하나 1차 목표 아님)
- 학부모 앱

## 7. 성공 기준

MVP가 성공했다고 말할 수 있는 조건:

1. 단어 시험(A유형) 1회 30장 채점이 **수기 대비 절반 이하 시간**에 끝난다.
2. 자동 확정된 문항에서 **오채점이 사실상 발생하지 않는다.**
   (선생님이 "이거 믿어도 되나" 하고 전부 다시 보게 되면 실패입니다.)
3. 선생님이 **다음 시험에도 자발적으로 쓴다.**
