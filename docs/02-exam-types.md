# 02. 시험지 유형 분석

실제 사용 중인 시험지 5종을 분석해 **자동채점 관점의 5개 유형(A~E)** 으로 분류했습니다.
개발 순서와 채점 전략은 전부 이 분류를 기준으로 정합니다.

## 요약

| 유형 | 대표 시험지 | 답안 형태 | 자동채점 적합도 | 개발 단계 |
|---|---|---|---|---|
| **A** | 미강고1 유&반의어 Test | 선택형(유/반) + 한글 뜻 단답 | ★★★★★ | Phase 1 |
| **B** | 은가람중2 본문 빈칸 | 문장 속 영단어 빈칸 (문항당 다수) | ★★★★☆ | Phase 1 |
| **C** | 윤슬·미강3 문법 문장 | 영어 문장 전체 영작 | ★★★☆☆ | Phase 2 |
| **D** | 미강중2 본문분석 TEST | 선택형·단답·서술 혼합, 위치 산재 | ★★☆☆☆ | Phase 3 |
| **E** | 미강고1 서술형대비 | 조건부 영작, 오류 수정 | ★☆☆☆☆ | Phase 3 |

---

## A유형 — 선택형 + 단어 뜻 쓰기

**구조**: 1~20번이 2단 격자로 고정 반복. 문항마다 `유 / 반` 선택 영역 + `뜻:` 작성선.
상단에 CLASS·담당T·재시험·이름란.

**왜 쉬운가**
- 답안 위치가 **완벽하게 규칙적**이다. 한 문항의 좌표만 지정하면 나머지 19개는 복제로 끝난다.
- `유/반`은 사실상 2지선다 OMR이다.
- 뜻은 짧은 한국어 단어이고, **정답 후보 집합이 작다.** 백지에서 읽는 게 아니라
  "응답하다 / 대답하다 / 반응하다 중 무엇인가"를 판별하는 문제로 축소된다.
- PASS 기준(`-3까지 PASS`)이 명확해 자동 판정 가능하다.

**채점 전략**
```
유/반  → 마킹 판독 (픽셀 밀도 + 위치)
뜻     → 손글씨 인식 + 인정 답안 사전 매칭 (정규화 후 편집거리)
       → 매칭 실패 or 확신도 낮음 → 교사 검수
결과   → 틀린 개수 자동 집계 → PASS/FAIL → 재시험 명단
```

**양식 수정 사항** (전부 눈에 띄지 않는 수준)
- `유 / 반` 사이 간격 확보, 각 선택지를 ○ 안에 배치
- `뜻:` 작성선 높이 9mm 이상, 선은 연회색(인식 시 노이즈 감소)
- 페이지 모서리 기준 마커 4개 + 우상단 QR

> **Phase 1의 1순위.** 학원에서 가장 자주 보는 시험이고, 자동화 효과가 가장 크며,
> 기술적으로 가장 안전합니다.

## B유형 — 본문 빈칸

**구조**: 본문 문장 33개, 문장 중간중간에 빈칸. 학생이 빠진 영단어를 채워 넣음.
상단에 `틀린 개수 /33`, 재시 일정, 채점자란.

**난점**
- **한 문항 안에 빈칸이 여러 개**다. (`In ____, there ____ ____ famous cook...`)
- 빈칸이 짧고 촘촘해서 글씨가 칸을 벗어나기 쉽다.
- 인접 빈칸의 글씨가 서로 침범할 수 있다.

**채점 전략 — 문장 단위 채점**
빈칸 하나하나를 개별 점수화하지 않고, **문항(문장) 단위로 정답/오답**을 판정합니다.
선생님이 실제로 채점하는 방식과 같고, 빈칸 1개 인식 실패가 문항 전체를 무효로 만들지 않습니다.

```
문항 = [빈칸1, 빈칸2, ... 빈칸n]
각 빈칸 인식 → 정답 단어와 비교
  모두 일치            → 정답 (자동 확정)
  1개 이상 명백히 불일치 → 오답 (자동 확정)
  1개라도 확신도 낮음    → 문항 전체를 교사 검수로
```
검수 화면에는 **문장 전체 crop 한 장**을 보여줍니다. 빈칸 5개를 따로 보는 것보다
선생님이 판단하기 훨씬 빠릅니다.

**양식 수정 사항**
- 빈칸 높이 9mm 이상, 빈칸 최소 길이 확보
- 문항 간 행간 확보 (윗줄 글씨가 아랫줄 빈칸을 침범하지 않게)
- 문항 번호를 왼쪽 고정 열에 배치 (정합 보조 기준점 역할)

## C유형 — 문장 영작 / 문장 암기

**구조**: 한국어 문장 + 힌트 단어 제시 → 학생이 영어 문장 전체를 작성.

**난점**
- 손글씨 **영어 문장 전체** 인식 → 오류 누적 가능성이 A·B보다 훨씬 큼
- 정답 문장과 글자 그대로 같지 않아도 맞는 경우가 있음
- 반대로 이 시험은 **"문장을 정확히 암기했는가"** 를 보는 시험이므로,
  AI가 관대하게 채점하면 시험의 목적이 무너짐

**채점 전략 — AI 1차 채점 + 교사 검수**
문자열 비교로는 부족하고, 채점 기준을 **선생님이 항목별로 설정**할 수 있어야 합니다.

| 오류 항목 | 기본값 | 교사 조정 |
|---|---|---|
| 단어 누락 | 오답 | 고정 |
| 시제 오류 | 오답 | 고정 |
| 관계대명사 오류 | 오답 | 고정 |
| 어순 오류 | 오답 | 고정 |
| 관사 누락 | 오답 | 허용 가능 |
| 쉼표 누락 | 정답 | 감점으로 변경 가능 |
| 대소문자 오류 | 정답 | 감점으로 변경 가능 |
| 철자 1글자 오류 | 교사 확인 | 정답/오답으로 고정 가능 |

AI는 판정만 하는 게 아니라 **"어디가 왜 틀렸는지"** 를 반환해야 하며,
검수 화면에서 원본 손글씨 이미지와 나란히 보여줍니다.

**선행 확인 필요**: 현재 확보된 샘플은 정답이 인쇄된 교사용입니다.
**학생용 문제지에서 `→` 뒤에 확보되는 실제 작성 공간**을 확인해야 합니다.
공간이 좁으면 글씨가 겹쳐 인식이 어렵습니다.

## D유형 — 본문분석 혼합형

**구조**: 한 시험지 안에 선택형(`at / in`, `so / but`), 짧은 서술(to부정사 용법),
지시어 의미 쓰기, 수동태 전환 서술이 뒤섞여 있음.

**난점**
- **답안 위치가 본문 곳곳에 흩어져 있다.** 문장 사이, 문장 위, 문장 옆.
- 이게 D유형이 어려운 진짜 이유입니다. 인식 난이도가 아니라 **좌표 등록 난이도**입니다.
  템플릿 하나 만드는 데 선생님이 30분 걸리면 아무도 안 씁니다.

**채점 전략 — 부분 자동화**
```
선택형(at/in)        → 마킹 판독, 자동 확정
지시어 의미(단어)     → 단답 인식 + 사전 매칭, 자동 확정
문법 용법 서술        → 키워드 채점 ("부사적 용법" 등 핵심어 포함 여부)
수동태 전환 문장      → AI 채점 + 교사 확인
```

**양식 수정 사항** (D유형은 수정 폭이 가장 큼)
- 답안마다 작은 번호 부여 — `① (at / in)`, `② *to부정사의 용법`
- 선택형은 동그라미 위치를 고정
- 서술형 답안선을 한 줄로 통일
- 답안 영역과 본문 사이 여백 3mm 이상

---

## E유형 — 고난도 서술형

**구조**: 지문마다 서술형 1(틀린 부분 수정) / 2(본문 기반 단어 빈칸) / 3(조건부 요약 영작).

| 문항 | 적합도 | 처리 |
|---|---|---|
| 서술형 1 (오류 수정) | 중 | AI 채점 → 확신도 낮은 것만 검수 |
| 서술형 2 (A~D 빈칸) | **높음** | 단답 인식 + 비교, 자동 확정 |
| 서술형 3 (조건 영작) | 낮음 | AI는 **조건 충족 여부만 체크**, 점수는 교사 확정 |

**서술형 3은 자동으로 점수를 확정하지 않습니다.** 대신 AI가 체크리스트를 제시합니다.

```
서술형 3 · AI 검토 결과
  제시어 12개 중 12개 사용      ✅ 충족
  형태 변형 3개                 ✅ 충족 추정
  동명사 주어 사용              ✅ 충족
  분사구문 사용                 ⚠️ 불확실
  문맥 적합성                   ⚠️ 확인 필요
  → 부분점수 가능 / 교사 확정 필요
```

선생님의 부담이 "처음부터 읽기"에서 "확인하고 누르기"로 바뀌는 것 자체가 이득입니다.

---

## 공통 결론

시험지를 하나의 양식으로 통일하지 **않습니다.**
대신 **양식별 템플릿을 등록**하고, 문항 유형별 채점기를 조합해 처리합니다.

이 구조 덕분에 새로운 선생님이 새로운 양식을 들고 와도
템플릿만 등록하면 기존 채점 엔진을 그대로 사용할 수 있습니다.
