# GradeSnap

**찍으면 채점되는 AI 답안 채점 시스템**
*AI-powered handwritten test grading system*

선생님이 기존에 쓰던 시험지를 **그대로 둔 채**, 학생이 손으로 작성한 답안지를
휴대폰으로 촬영하면 자동으로 채점하고 오답·재시험 대상까지 뽑아주는 시스템입니다.

---

## 한 줄 흐름

```
휴대폰 촬영 / 일괄 업로드
        ↓
AI가 페이지 전체를 문항별로 전사 (번호 · 인쇄된 제시어 · 학생이 쓴 답)
        ↓
규칙으로 정오 판정 (채점 기준은 선생님이 정함)
        ↓
확신도 높음 → 자동 확정
확신도 낮음 → 부분 확대 재질의 → 교사 검수
        ↓
점수 · 오답 번호 · PASS/FAIL · 재시험 명단 · 리포트
```

**시험지에 등록할 것이 없습니다.** 템플릿도, 좌표도, 기준 마커도, QR도 없습니다.
→ [12. 페이지 단위 채점](docs/12-page-level-grading.md)

## 핵심 설계 원칙

1. **시험지는 손대지 않는다.** 마커도 QR도 넣지 않습니다. 선생님은 지금 쓰던 것을
   그대로 인쇄해 쓰면 됩니다. 양식이 매번 바뀌어도 상관없습니다.
2. **읽는 것과 판정하는 것을 분리한다.** AI는 "학생이 쓴 글자"를 옮기기만 하고,
   맞았는지는 규칙이 정합니다. 이래야 AI가 틀린 답을 정답으로 "고쳐 읽는" 걸 막습니다.
3. **틀린 자동채점보다 느린 채점이 낫다.** 확신도가 낮으면 무조건 교사에게 넘깁니다.
   목표는 "채점 0분"이 아니라 "채점 시간 80% 절감 + 오채점 0에 수렴"입니다.
4. **조교는 사진만 찍는다.** 장마다 무언가 입력해야 하면 이 시스템은 쓸 이유가 없습니다.
   반·시험·커트라인·문항 수는 전부 시험지 머리말에서 읽습니다. 입력 항목 0개가 목표입니다.
5. **행 밀림을 항상 검증한다.** 좌표가 없는 대신 **인쇄된 문항 번호와 제시어를 함께
   읽게 해서** 정렬을 확인합니다. 이 방식의 유일한 치명적 실패 모드입니다.

## 현재 상태

**Phase 0 진행 중.** 2026-08-07에 설계를 전환했습니다 → [12](docs/12-page-level-grading.md)

기존 설계는 템플릿 좌표로 칸을 잘라 하나씩 읽히는 방식이었습니다. 실제 답안지를
분석하는 과정에서 **템플릿 없이 사진만 보고 세 장의 오답을 짚었고 선생님 채점과
정확히 일치**했습니다. 양식이 셋 다 달랐습니다. 비용을 계산해 보니 통짜로 넣는 쪽이
오히려 **약 5배 쌌습니다**. 기존 설계의 근거 세 개 중 둘이 무너져 방향을 바꿨습니다.

이 전환으로 로드맵의 최상위 리스크였던 **"매회 새로 만드는 시험지의 등록 비용"이
사라집니다.** 등록할 것이 없기 때문입니다.

### 다음 작업

`grade_page.py`를 실제 답안지 6쌍(채점 전/후)에 돌려 네 가지를 실측합니다.

| 재는 것 | 기준 |
|---|---|
| 선생님 채점 일치율 | 95% 이상 |
| 놓친 오답 (선생님은 틀렸다는데 우리는 맞다 함) | 1% 미만 |
| 행 밀림 경보 | 0장 |
| 비결정성 (같은 사진 3회) | 흔들린 칸은 검수로 라우팅 |
