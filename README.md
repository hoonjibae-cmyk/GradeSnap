# GradeSnap

**찍으면 채점되는 AI 답안 채점 시스템**
*AI-powered handwritten test grading system*

선생님이 기존에 쓰던 시험지 양식을 그대로 유지한 채, 학생이 손으로 작성한 답안지를
휴대폰으로 촬영하면 자동으로 채점하고 오답·재시험 대상까지 뽑아주는 시스템입니다.

---

## 한 줄 흐름

```
시험지 템플릿 등록 (PDF + 답안 영역 좌표 + 정답표)
        ↓
인쇄 → 학생 응시 (기존과 동일)
        ↓
휴대폰 촬영 / 일괄 업로드
        ↓
보정 → 시험지 식별(QR) → 정합 → 답안 영역 crop
        ↓
유형별 채점 (OMR / OCR / AI)
        ↓
확신도 높음 → 자동 확정
확신도 낮음 → 교사 검수 화면
        ↓
점수 · 오답 번호 · PASS/FAIL · 재시험 명단 · 리포트
```

## 핵심 설계 원칙

1. **양식은 유지, 답안 영역만 정리한다.** 선생님이 만든 시험지를 갈아엎지 않습니다.
   기준 마커·QR·답안선 규격만 최소한으로 추가합니다. → [양식 가이드](docs/06-exam-form-guide.md)
2. **정답을 알고 읽는다.** 백지 상태에서 손글씨를 읽는 게 아니라, "이 칸에 올 수 있는 답"을
   알고 있는 상태에서 인식합니다. 인식 정확도가 근본적으로 달라지는 지점입니다.
3. **틀린 자동채점보다 느린 채점이 낫다.** 확신도가 낮으면 무조건 교사에게 넘깁니다.
   목표는 "채점 0분"이 아니라 "채점 시간 80% 절감 + 오채점 0에 수렴"입니다.
4. **가장 쉬운 시험지부터.** 5개 유형을 한 번에 하지 않고 A유형(선택형+단답)부터 출시합니다.
