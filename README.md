# GradeSnap

**찍으면 채점되는 AI 답안 채점 시스템**
*AI-powered handwritten test grading system*

선생님이 기존에 쓰던 시험지 양식을 그대로 유지한 채, 학생이 손으로 작성한 답안지를
휴대폰으로 촬영하면 자동으로 채점하고 오답·재시험 대상까지 뽑아주는 시스템입니다.

---

## 한 줄 흐름

```
시험지 템플릿 등록 (PDF + 답안 영역 좌표 + 정답표)
        ↓
인쇄 → 학생 응시 (기존과 동일)
        ↓
휴대폰 촬영 / 일괄 업로드
        ↓
보정 → 시험지 식별(QR) → 정합 → 답안 영역 crop
        ↓
유형별 채점 (OMR / OCR / AI)
        ↓
확신도 높음 → 자동 확정
확신도 낮음 → 교사 검수 화면
        ↓
점수 · 오답 번호 · PASS/FAIL · 재시험 명단 · 리포트
```

## 핵심 설계 원칙

1. **양식은 유지, 답안 영역만 정리한다.** 선생님이 만든 시험지를 갈아엎지 않습니다.
   기준 마커·QR·답안선 규격만 최소한으로 추가합니다. → [양식 가이드](docs/06-exam-form-guide.md)
2. **정답을 알고 읽는다.** 백지 상태에서 손글씨를 읽는 게 아니라, "이 칸에 올 수 있는 답"을
   알고 있는 상태에서 인식합니다. 인식 정확도가 근본적으로 달라지는 지점입니다.
3. **틀린 자동채점보다 느린 채점이 낫다.** 확신도가 낮으면 무조건 교사에게 넘깁니다.
   목표는 "채점 0분"이 아니라 "채점 시간 80% 절감 + 오채점 0에 수렴"입니다.
4. **가장 쉬운 시험지부터.** 5개 유형을 한 번에 하지 않고 A유형(선택형+단답)부터 출시합니다.

## 현재 상태

기획 단계입니다. 코드는 아직 없습니다.

**Phase 0 진행 중** — 실제 답안지 약 55장 분석 완료([08](docs/08-sample-analysis.md)),
유니크보카 생성기 분석 완료([09](docs/09-yunique-voca-integration.md)).

시험지는 만들어지는 방식이 세 가지이고, **등록·운영 비용이 각각 다릅니다.**
([04 §2.5](docs/04-data-model.md#25-시험지-3분류--등록운영-비용이-다릅니다))

| 분류 | 예시 | 매회 작업 |
|---|---|---|
| ① 생성기 출력 | 유니크보카 | 없음 (examSpec 자동 수신) |
| ② 고정 세트 | 문법 백지 TEST | 없음 (유닛당 1회 등록) |
| ③ **매회 신규** | 영작클리닉, Day08-10 단어시험 | **매회 전체 등록** |

③은 선생님이 매회 시험지를 새로 만들고 공유되는 건 상단 헤더 표뿐입니다.
본문에 양식이 없어 좌표를 재사용할 수 없으므로, **등록을 5분 이내로 만드는 것이
이 프로젝트의 성패를 가릅니다.** 등록 시간이 채점 절감 시간보다 길면 도입할 이유가 없습니다.

> ⚠️ 경로 A는 유니크보카 쪽에 **출제 이력 저장 기능을 먼저 추가**해야 합니다.
> 현재는 문항이 매번 무작위로 섞이고 결과가 저장되지 않아,
> 인쇄된 시험지의 몇 번이 어떤 단어였는지 알 방법이 없습니다.

> 학생 답안지 이미지는 실명·필체 등 개인정보를 포함하므로 **저장소에 커밋하지 않습니다.**
> 로컬 `samples/`에 보관하며 `.gitignore`로 제외되어 있습니다.
